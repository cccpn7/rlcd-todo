# 钓任务布局试样 02

独立浏览器原型，仅使用通用样例，不连接待办服务、SS49E或设备。现有鱼缸固件不变。

```sh
python3 -m http.server 8877 --bind 127.0.0.1 --directory prototypes
```

打开 `http://127.0.0.1:8877/task-fishing/`。从项目根目录运行。

## 布局与鱼形

- 原生逻辑画布300×400、纯黑白。默认放大1.2倍，可切回原始像素。
- 移除顶部名称和日期，水面位于y≈12；喂食从画面顶端落下，鱼线从y=0垂下。
- 右上方水面处为迷你鱼护，约61×52px；鱼护中的鱼约32–46px宽。
- 右下任务牌位置保留，斑鱼标志移到牌子上；正文18px、每页两行，长原文完整翻页。揭晓提示使用20px，超长内容注明可在牌子看全文。
- 六种原创像素鱼：梭形、圆背、神仙、条纹、长尾、扇尾。参考用户提供的热带鱼形态方向自行绘制，纯黑白，不嵌入参考图片。每条随机选一种，任务关联不随鱼形改变。
- 鱼身无字，花纹不代表分类。鱼自由游动，移除鱼间碰撞／避让；保留画面边界和牌子周边的游动范围。

## 操作

1. “S极·靠近鱼竿”：鱼钩从顶端下落约0.8秒，在水中等2秒，其间鱼继续游动；然后选中的鱼约1.1秒游来咬钩。
2. “拿开鱼竿”：提竿后揭晓任务约2.2秒，自动记为当前任务并入鱼护，文字同步到小牌子。无需接下／放回确认，钓到什么做什么。
3. 鱼护非空时不会抽第二件，提示先完成当前任务。
4. “模拟大圣／网页”的完成按钮让鱼离场；撤销完成让鱼回游动区。不是实物完成按钮。
5. 切换0／3／8／15件任务、短／长标题时重置演示并重新随机鱼形。

常驻鱼和追踪任务不参与抽取；重点和杂项按任务合并等概率抽取，不按鱼形、位置、速度加权。

## 验证与范围

```sh
node --test prototypes/task-fishing/model.test.mjs
```

模型检查抽取区间、下钩后等待、提竿自动入护、完成／撤销与原文完整性。浏览器检查揭晓后无需确认、自动显示牌子、长文翻页、375px窄屏和脚本错误。

本次仍是布局与操作原型。自由游动已实现；撒粮仅示意顶端落粮，原版追食行为尚未合并。真实磁极、提前拿开鱼竿的实物处理、网络同步、字体和性能另行验证。没有修改或烧录固件。

2026-11-27补充确认：3条常驻鱼恢复原样、原尺寸及“思／闪／点”文字，水草恢复原有素材。只有新增任务鱼使用小型随机外观。

喂鱼现可放回鱼护内任务鱼，牌子回初始状态；同一条任务鱼仍未完成、重新可抽。网页含约0.9秒游回动画，与固件同步。
