# 鱼缸交互原型

第一阶段视觉确认材料，独立浏览器程序，不访问设备、任务接口或真实清单。原创纯黑白像素鱼；画布300×400、目标12帧/秒。浏览器字体栅格化不代表最终固件字形或真屏观感。

小鱼按最新反馈放大为原来的1.5倍（当前轮廓约54×28px），分别标“思”“闪”“点”。根据用户提供的像素鱼参考，改为梭形白色鱼身、黑色像素轮廓、分叉尾巴、突出的背鳍和腹鳍、大眼睛与鳃线；鱼身黑字，转向时文字保持正向。追食速度进一步降为60px/秒，每口停顿650ms，鱼粮沉降也放缓。鱼的位置以身体中心计算，转向不会使身体跳位；完整轮廓有56×32px碰撞范围，鱼会绕开其他鱼、另选可达食物，不能相互穿过或越出鱼缸。

鱼粮按参考截图改为24颗约4–10px混合颗粒：空心圆环搭配实心碎粒，分批从顶部中央撒下、向两侧散开、轻微摆动，沉降速度略有差异。小鱼追逐附近鱼粮，碰到后吃掉；不再限制6–8秒，实际吃完后再停留900ms进入待办，180秒仍从待办显示开始。已参考截图外观，未观看视频，运动为本项目设计。

左上角以48×32px“斑鱼”图形替换“小鱼缸”文字：参考用户提供的斑马标志设计条纹尾巴、圆脸、笑嘴和鱼鳍，使用纯黑白像素。`logo.mjs` 是画面使用的像素源，`ban-yu-logo.svg` 是同源放大预览；不引入绿色背景。待办页仍显示分类标题。

在项目根目录运行：

```sh
python3 -m http.server 8876 --bind 127.0.0.1 --directory prototypes/aquarium
```

打开 `http://127.0.0.1:8876`。点击“靠近鱼粮瓶”模拟持续存在的磁铁，再次点击拿开。鱼缸和待办状态均接受新的靠近或 KEY 短按喂鱼，吃完重新展示待办3分钟；仅喂食中忽略重复触发。磁铁须移开500ms、再次靠近150ms，持续放置不连发。三分钟为真实计时，演示工具可跳到最后5秒；不会缩短正式规则。

```sh
node --test prototypes/aquarium/model.test.mjs
```

验证节奏、原文示例页面、空分类与状态切换；不能替代SS49E ADC校准、通信、实际帧率和硬件验收。浏览器休眠不用于证明设备单调时钟计时。
