# 决策记录

## 2026-09-28：第一版范围与 UI 修订

| 决策 | 原因／边界 |
| --- | --- |
| 今日重点、今日杂项、今日追踪三份平级清单 | 个人每日速览，项目管理留在已有系统 |
| Mac 网页输入，显式更新屏幕 | 自动保存方便编辑，避免修改一半被同步 |
| 未完成跨日保留，完成记录可恢复 | 无需每天搬运，也不自动复制事项 |
| USB 与 BLE 均属于第一版，USB 优先 | 公司网络不能同时接入 Mac 与设备 |
| 只连 Mac | 不扩展手机直连、账号或公网服务 |
| 300×400 竖屏，正文 18px / 行高 24px | 根据用户反馈缩小字号，提高每屏容量 |
| 分类 18px 加粗，与 12px 日期同一行 | 避免分类标题占用过多正文空间 |
| 原文完整，长文跨页续接 | 用户明确要求不省略、不改写 |
| Mac 统一排版，设备缓存黑白页面 | 网页与真屏的文字和分页相同；设备只显示和翻页 |
| RTC 叠加日期、双份缓存、确认后报成功 | 断开 Mac 后继续使用，不误报完成 |
| ESP-IDF 5.5.2 / LVGL 9.4.0 | 复用已验证工具链，修正官方竖屏索引 |
| 版本化 API，来源编号幂等 | 未来大圣复用，不在本版实现提取和冲突判断 |
| 功能分支、真实数据仅本地 | 公开仓库不包含工作资料、身份、凭据或日志 |

替代初始化版本的 Wi-Fi、30 秒轮询、长文本省略和手机编辑假设。首版不增加项目层级、语音、计时、提醒、多用户或自动重要性判断。

项目自身暂未选择许可证；引入的 Waveshare 显示驱动按 Apache-2.0 保留声明，思源黑体按 SIL OFL 1.1 保留声明。
