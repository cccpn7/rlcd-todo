# 桌面待办纸：第一版实施计划

本版依据已确认的紧凑 UI 方案实施。功能实现、编译、通信、烧录和真屏验收分别记录；实现不等于已经完成日常试用。

## 产品与使用规则

个人每日快速待办纸，放在显示器旁，观看距离 50–70 厘米。固定三份独立、平级清单：今日重点、今日杂项、今日追踪。不建立项目库、父子任务或自动优先级，也不从部门项目中自行筛选。

第一版由 Mac 网页填写，未来大圣整理后推送到同一服务。未完成事项跨日保留分类与顺序；已完成事项留在网页记录，可以撤销。网页修改自动保存为草稿，点击“更新屏幕”后整份发布。设备只负责显示和翻页，通过 USB 或 BLE 连接 Mac，不依赖 Wi-Fi。

## 网页与设备 UI

网页沿用已确认布局：左侧三份清单，右侧设备预览，顶部连接状态与发布按钮。支持新增、编辑、删除、上下排序、移分类、完成与撤销、逐行批量添加。已完成列表折叠。分别预览草稿与已发布内容；离线发布保留在 Mac，重连发送最新发布版本。

| 设备元素 | 规格 |
| --- | --- |
| 画面 | 300×400 竖屏，严格黑白 |
| 分类标题 | 18px 加粗，与日期同一行 |
| 日期／底栏 | 12px；日期、分类内页码、最后更新时间、连接状态 |
| 正文 | 18px，24px 行高，条目间距 6px |
| 左右边距 | 12px |

保留完整原文，不改写、不省略、不自动缩小字号。按实际文字高度分页；能放进整页的事项尽量不拆，超过整页则保留编号并标“续”。换行采用悬挂缩进。空分类显示“暂无事项”，不填充无关内容。发布前报告不支持的字符。

KEY 短按下一页，BOOT 短按上一页，按重点→杂项→追踪循环；KEY 长按 800ms 回重点首页。不轮播；新发布内容显示成功后回首页。按键去抖 30ms，长按 KEY 松开不会额外翻页。

Mac 使用同一字体与分页引擎生成网页预览和设备黑白页面。原始事项保存在 SQLite，设备收到页面快照，LVGL 显示并叠加实时日期和连接状态。概念草图并非像素精确验收；最终在真实桌面光线和观看距离下确认。

## 系统与接口

Mac：Python 3.12、FastAPI、SQLite、普通 HTML/CSS/JavaScript，仅监听本机。关闭网页不停止服务，休眠期间停止同步，恢复后重连。稳定任务编号、原文、分类、顺序、完成状态、更新时间、来源名称／编号。草稿与已发布快照分开保存。

设备：ESP-IDF 5.5.2、LVGL 9.4.0，修正竖屏像素索引，原生 USB 串口和 NimBLE GATT。Mac 使用 pyserial、Bleak。首次通过 USB 绑定稳定设备标识，蓝牙使用系统配对及设备屏幕显示的密码。有效 USB 握手优先，否则使用已绑定 BLE。数据线更换插口不改变绑定。

共用版本化消息协议：握手、传输开始、分块、SHA-256 校验、完成确认。初始完整快照上限 128KiB、最多 128 个屏幕页，超限保留草稿并提示，不截断。版本单调递增；旧版拒绝，相同版本仅允许相同内容。设备双份缓存，最后写入提交标记；全部校验、持久化、刷新屏幕后确认成功。重连只发送最新发布版本，草稿不自动发布。

时区 Asia/Shanghai；RTC 保存 UTC。Mac 握手校时，设备独立推进日期，跨日不复制任务。无有效时钟显示 `--.--`；没有缓存时提示首次同步。失联显示 `OFF` 并继续显示原内容。

`/api/v1` 提供任务读写、发布、状态和预览。来源名称＋来源编号唯一，重复推送更新同一事项。第一版只验证模拟大圣推送，不实现任务提取、自动判断或跨系统冲突处理。

## 实施与协作

1. 同步规范与 UI，移除旧版 Wi-Fi、轮询和省略文本规则。
2. 本地备份出厂固件，修正竖屏，验证四角、长文本、字体及按键；产品负责人确认真屏可读性。
3. 打通网页、USB、草稿／发布和缓存。
4. 完成 BLE 配对、USB 优先、断线恢复；产品负责人配合系统授权与物理插拔。
5. 连续使用 3–5 个工作日，完成模拟外部推送和使用说明。

真实待办和设备标识仅留本地；公开仓库使用通用样例。功能分支小步提交，保留第三方许可，不强推主分支。

## 验收

- 三类、空态、长文本、跨页、四角和按键正确，无裁字、丢字、越界或异常复位。
- 草稿不提前显示，显式发布后分类、顺序、完成状态一致；跨日和服务重启不丢内容。
- 已连接时，100 条混合长短事项、任务文本不超过 20KiB，USB 与 BLE 分别在发布后 35 秒内确认；实际传输的是渲染快照，同时受 128KiB 上限约束。大快照另测耗时。
- 更换插口、传输中断、Mac 休眠、设备断电后保留有效缓存并追上最新版；“已更新”来自设备保存和刷新确认。
- 50–70 厘米真屏可读；3–5 个工作日后能帮助快速找回重点，维护成本可接受。
