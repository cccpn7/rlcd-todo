# 验证范围

自动测试：`python -m pytest -q`，覆盖草稿／发布隔离、持久化、完成撤销、来源编号幂等、排序、删除和批量、缺字阻止发布、同源保护、长文本字符完整性、分页边界、压缩还原和容量。

`./scripts/test-core.sh` 使用未定义行为与数组边界检查器运行固件核心解析器，检查 120000 个像素映射无重复、四角无越界、有效快照解析及截断包拒绝。

`python scripts/check-device.py usb --benchmark` 与 `ble --benchmark` 为真机测试，需先停止服务；会临时发送 100 条通用事项，再恢复最近已发布内容。记录只保存在 local/。不要误认为后台构建会运行真机测试。

手工验收：正常桌面光线下 50–70 厘米可读、画面四角、空态与跨页、短按与长按、Mac 休眠和物理断电、拔插数据线、蓝牙配对、关闭网页后服务仍运行、3–5 个工作日日常价值。结果见 docs/validation.md，未实测的项目必须标记待验证。
