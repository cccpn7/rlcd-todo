# 验证范围

自动测试：`python -m pytest -q`，覆盖草稿／发布隔离、持久化、完成撤销、来源编号幂等、排序、删除和批量、缺字阻止发布、同源保护、长文本字符完整性、分页边界、压缩还原和容量。

`./scripts/test-core.sh` 使用未定义行为与数组边界检查器运行固件核心解析器，检查 120000 个像素映射无重复、四角无越界、有效快照解析及截断包拒绝。

下述旧图片模式命令不能用于已迁移的 RTD4 固件：`python scripts/check-device.py usb --benchmark` 与 `ble --benchmark` 为旧版真机测试，需先停止服务；会临时发送 100 条通用事项，再恢复最近已发布内容。记录只保存在 local/。不要误认为后台构建会运行真机测试。

手工验收：正常桌面光线下 50–70 厘米可读、画面四角、空态与跨页、短按与长按、Mac 休眠和物理断电、拔插数据线、蓝牙配对、关闭网页后服务仍运行、3–5 个工作日日常价值。结果见 docs/validation.md，未实测的项目必须标记待验证。

自动轮播测试包含在 `./scripts/test-core.sh` 中：5 秒边界、跨分类子页与首尾循环、手动操作和发布后的计时重置、配对／按键暂停恢复、延迟不跳页、无缓存静止。该测试使用模拟单调时间验证固件同一份计时逻辑，不能替代真机持续观察和按键验收。

## 设备直连版

`tests/test_remote.py` 覆盖角色权限、可信本人确认、过期/冲突/重复确认、来源幂等、删除恢复、长轮询唤醒、代理同源检查及持久化结果通知（模拟投递，不能代替真实双端验收）。

`./scripts/test-text-layout.sh` 从同一字体生成 RLF1 字库，用未定义行为和边界检查器验证固件实际 RTD4 解析、UTF-8、长文分页与绘制。`./scripts/test-core.sh` 继续检查兼容缓存、像素映射和轮播逻辑。

新模式手动补发使用 `scripts/maintain-device.py push --transport usb` 或 `ble`，仅转发服务端最近发布的同一快照。实测结果与待验证项以 `docs/validation.md` 为准，私有原始记录不提交。
